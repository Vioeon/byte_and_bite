# 🗺️ Site Map

```text
🏠 사이트 홈 (/)
├── 회원가입 (/signup)
└── 로그인 (/login)

🔑 메인 페이지 (/posts)
├── 🍽️ 맛집 리뷰 게시판
│   ├── 게시글 목록 조회 (최신순)
│   ├── 게시글 목록 조회 (인기순)
│   ├── 게시글 제목 검색
│   ├── 게시글 카테고리 검색
│   ├── 게시글 작성
│   ├── 좋아요한 게시글 목록 조회
│   └── 게시글 상세 페이지 (/posts/{id})
│       ├── 게시글 상세 조회
│       ├── 게시글 수정
│       ├── 게시글 삭제
│       ├── 게시글 좋아요
│       ├── 조회수 증가
│       ├── 댓글 목록 조회
│       ├── 댓글 작성
│       ├── 댓글 수정
│       ├── 댓글 삭제
│       ├── 게시글 신고
│       └── 댓글 신고
│
├── ❓ Q&A 게시판 (/qna)
│   ├── 질문 게시글 목록 조회 (최신순)
│   ├── 질문 제목 검색
│   ├── 지역별 질문 조회
│   ├── 질문 게시글 작성
│   └── 질문 상세 페이지 (/qna/{id})
│       ├── 질문 수정
│       ├── 질문 삭제
│       ├── 답변 작성
│       │   └── 맛집 리뷰 게시글 링크 첨부
│       ├── 답변 수정
│       ├── 답변 삭제
│       ├── 답변 채택
│       └── 채택된 답변 상단 고정
│
└── 👤 마이페이지 (/mypage)
    ├── 회원정보 조회
    ├── 회원정보 수정
    ├── 회원탈퇴
    ├── 내가 작성한 게시글 목록 조회
    └── 내가 작성한 댓글 목록 조회
        └── 해당 게시글 이동

🛡️ 관리자 페이지 (/admin)
├── 관리자 계정 생성
├── 회원 목록 조회
├── 전체 게시글 삭제
├── 전체 댓글 삭제
│
├── 🚨 신고 관리
│   ├── 신고 목록 조회
│   ├── 신고 상세 조회
│   ├── 신고된 게시글 삭제
│   ├── 신고된 댓글 삭제
│   ├── 신고 대상 회원 정지
│   └── 신고 대상 회원 탈퇴
│
└── 회원 관리
    └── 회원 목록 조회
```
