## 1.1.1 회원(Member)

| 요구사항 ID | 구분 | 기능명 | 담당자 | 우선순위 | 상세 내용 |
|---|---|---|---|---|---|
| REQ-MEMBER-001 | 회원 | 회원가입 | 이승언 | 1 | 사용자가 회원 정보를 입력하여 계정을 생성할 수 있다. (사용자와 식당 관계자를 구분하며, 식당 관계자 가입시 식당 정보를 등록한다. |
| REQ-MEMBER-002 | 회원 | 회원가입 페이지 UI 구현 | 이승언 | 1 | 회원가입 화면 UI를 구현한다. |
| REQ-MEMBER-003 | 회원 | 로그인 페이지 UI 구현 | 이승언 | 1 | 로그인 화면 UI를 구현한다. |
| REQ-MEMBER-004 | 회원 | 로그인 | 이승언 | 1 | 등록된 회원 정보를 통해 로그인을 처리한다. |
| REQ-MEMBER-005 | 회원 | 로그아웃 | 이승언 | 1 | 로그인 상태를 종료하고 세션을 제거한다. |
