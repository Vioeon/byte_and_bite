## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
맛집 추천 및 리뷰를 자유롭게 공유할 수 있는 Q&A 커뮤니티 서비스를 구축한다.  
(※ 서비스명은 추후 확정 후 기재)

### 1.1.2 서비스 주요 특징
- 맛집 리뷰 및 추천 게시글 작성, 상세 조회, 수정, 삭제(CRUD) 지원
- 게시글 추천 기능을 통한 인기 게시글 조회
- 답변 댓글 작성, 수정, 삭제 기능 제공
- 서버 사이드 렌더링(Thymeleaf)을 활용한 동적 화면 제공

---

## 1.2 주요 기능 요구사항

### 1.2.1 회원 관리 기능
- 회원가입 (이메일, 비밀번호, 이름, 전화번호)
- 로그인 및 로그아웃
- 마이페이지 회원 정보 조회 및 수정

### 1.2.2 게시글 관리 기능
- 맛집 리뷰 게시글 목록 조회 (페이징, 키워드 검색, 카테고리 검색, 인기순 정렬)
- 맛집 리뷰 게시글 상세 조회 (조회수 증가 처리)
- 게시글 추천 기능
- 게시글 작성, 수정, 삭제 (작성자 및 관리자 권한)

### 1.2.3 댓글 관리 기능
- 맛집 리뷰 상세 화면 내 댓글 작성
- 댓글 목록 조회
- 본인 댓글 수정 및 삭제 (관리자 제어 가능)

### 1.2.4 관리자 관리 기능
- 모든 게시글 관리
- 모든 댓글 관리
- 회원 관리

## 1.3 팀 구성 및 도메인별 역할 분담

### 1.3.1 팀명 및 역할 분담표 (팀명: 바이트)

| 이름 | 직책 | 담당 도메인 | 세부 구현 내용 |
| :--- | :--- | :--- | :--- |
| 이승언 | 팀장 | Q&A 관리 | 질문 게시판 관리 기능, 프로젝트 환경 구성 |
| 김혜란 | 발표 | 회원 관리 | 회원가입, 로그인/로그아웃, 마이페이지 |

| 김남규 | 팀원 | 관리자 기능 | 1대1 신고 게시판, 회원 정보 조회, 삭제 권한, 게시글 및 댓글 관리 |
| 윤승영 | 팀원 | 게시글 관리 | 게시글 목록, 상세 조회, 작성, 수정, 삭제, 검색 및 추천 기능 |

### 1.3.2 역할 분담 원칙
모든 팀원이 특정 기술 레이어에 치우치지 않고, 각자 맡은 기능에 대해 화면(UI)부터 DB 처리까지 수직 슬라이스(Vertical Slice) 형태로 구현한다.

### 1.3.3 팀원별 도메인 담당 정의

#### 1) 이승언 (팀장)
- 총괄 역할: 프로젝트 초기 환경 구성, Git/GitHub Projects 체계 수립
- 담당 도메인: 회원 관리 기능
- 구현 내용: 회원 관리 기능 (회원가입, 로그인/로그아웃, 마이페이지-회원정보 조회/수정/탈퇴), 전체회원 목록조회(관리자 페이지)

#### 2) 김혜란 (발표)
- 담당 도메인: 사용자 Q&A 질문 게시판
- 구현 내용: Q&A 목록, 답변 작성, 상세 조회, 작성, 수정, 삭제, 검색
- 
#### 3) 소지현 (서기)
- 담당 도메인: 댓글 관리 기능 (답변 댓글 작성, 삭제 및 수정)
- 구현 내용: 댓글 작성, 조회, 수정, 삭제

#### 4) 김남규 (팀원)
- 담당 도메인: 관리자 관련 기능
- 구현 내용: 1대1 신고 게시판 구현(문의 내역 조회, 해당 내용의 글 삭제 및 강제회원탈퇴), 회원 정보 조회, 모든 글과 댓글에 대한 삭제 권한 부여

#### 5) 윤승영 (팀원)
- 담당 도메인: 사용자 게시글(post), 좋아요(like) 기능
- 구현 내용: 게시글 작성, 목록 조회(최신순 / 인기순), 수정/삭제(작성자 및 관리자 권한), 검색(제목 / 카테고리), 게시글 인기순 정렬, 게시글 조회수 증가,
좋아요(좋아요 / 좋아요 취소), 좋아요 게시글 목록 조회(즐겨찾기)
