## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적

사용자는 실제 방문 경험을 바탕으로 맛집 리뷰를 공유하고, 식당은 이벤트·신메뉴·홍보 등의 최신 소식을 등록할 수 있는 맛집 커뮤니티 서비스를 구축한다.

이를 통해 사용자에게는 다양한 맛집 정보를 제공하고, 식당에는 고객에게 정보를 전달할 수 있는 홍보 채널을 제공하는 것을 목표로 한다.

---

### 1.1.2 서비스 주요 특징

- 회원가입 및 `HttpSession` 기반 로그인/로그아웃 세션 인증 처리
- 일반 사용자의 맛집 리뷰 작성, 상세 조회, 수정, 삭제(CRUD) 지원
- 맛집 운영자의 맛집 소식 작성, 상세 조회, 수정, 삭제(CRUD) 지원
- 리뷰 및 맛집 소식의 최신순·조회순 정렬, 카테고리 및 식당이름 검색 지원
- 리뷰 댓글 작성, 수정, 삭제 기능 제공
- 맛집 운영자의 식당 정보 등록 및 관리
- 마이페이지를 통한 회원 정보 및 작성 게시글 관리
- Thymeleaf 기반 Server Side Rendering(SSR) 적용

---

# 1.2 주요 기능 요구사항

## 1.2.1 회원 관리 기능

- 회원가입 (이메일, 비밀번호, 닉네임)
- 닉네임 중복 검사
- 일반 사용자 / 맛집 운영자 회원 유형 구분 
- 맛집 운영자 가입 시 식당 정보 등록
- HttpSession 기반 로그인 및 로그아웃
- 회원 탈퇴(Soft Delete)

---

## 1.2.2 맛집 리뷰 게시글 관련

- 리뷰 목록 조회
  - 최신순
  - 조회순
  - 카테고리별 조회
  - 식당이름 검색
  - 페이지네이션
- 리뷰 상세 조회
- 세션 기반 조회수 중복 증가 방지
- 리뷰 작성, 수정, 삭제

---

## 1.2.3 맛집 소식 게시글 관련

- 맛집 소식 목록 조회
  - 최신순
  - 조회순
  - 카테고리별 조회
  - 식당이름 검색
  - 페이지네이션
- 맛집 소식 상세 조회
- 세션 기반 조회수 중복 증가 방지
- 맛집 소식 작성, 수정, 삭제

---

## 1.2.4 댓글 관리 기능

- 리뷰 상세 페이지 내 댓글 목록 조회(페이지네이션)
- 댓글 작성
- 작성자 본인의 댓글 수정 및 삭제
- 맛집 운영자의 본인 식당 리뷰에 대한 댓글 작성 및 수정,삭제

---

## 1.2.5 등록 식당 관리 기능

- 맛집 운영자의 식당 정보 등록
- 등록된 식당 정보 조회
- 등록된 식당에 대한 리뷰, 소식 작성
- 식당별 이벤트 및 홍보 게시글 조회
- 식당 정보 수정(맛집 운영자)

---

## 1.2.6 마이페이지 관리 기능

### 일반 사용자

- 일반 사용자
    - 회원 정보 조회
    - 닉네임 변경
    - 회원 탈퇴
    - 작성한 리뷰 목록 및 상세 조회

### 맛집 운영자

- 맛집 운영자
    - 회원 정보 조회
    - 닉네임 변경
    - 회원 탈퇴
    - 등록한 식당 정보 조회 및 수정
    - 작성한 맛집 소식 목록 및 상세 조회

## 1.3.2 역할 분담 원칙

모든 팀원이 특정 기술 레이어에 치우치지 않고, 각자 맡은 기능에 대해 화면(UI)부터 DB 처리까지 직접 구현하는 **수직 슬라이스(Vertical Slice)** 방식으로 개발한다. 또한 GitHub를 활용한 브랜치 전략과 Pull Request 기반 협업을 통해 기능을 통합하고 프로젝트를 진행한다.
