## 📌 문제 발생

### 1. 문제 유형 (핵심 태그) 정의

- 이미지 출력
- 이미지 업로드
- 파일 경로 문제

### 2. 어떤 기능에서 문제가 발생했는가?

- 게시글 등록 후 화면에 이미지가 바로 출력되지 않고, 인텔리제이에서 테이블을 새로고침을 해야만 출력이 되는 현상.

- 맛집 리뷰 작성 기능에서 사용자가 업로드한 식당 이미지를 리뷰 상세 페이지와 목록 페이지에서 보여지는 이미지를 출력하는 과정에서 문제가 발생.

- 게시글 작성 시 이미지는 정상적으로 업로드되는 것처럼 보였으나, 게시글 조회 화면에서 이미지가 표시되지 않았고 브라우저 개발자 도구에서 이미지 요청이 `404 Not Found` 오류가 발생했고 이미지 경로가 중복으로 생성되는 문제 발생.
  
예시 ) /uploads/restaurant//uploads/restaurant/ex.png

---

## 🔍 원인 분석

### 왜 발생했는가?

- 이미지 파일 저장 위치가 static 폴더 내부에 image 폴더에 저장을 진행해서 발생

- 이미지 파일 저장 위치와 브라우저에서 접근하는 이미지 경로에 대한 기준이 일치하지 않았기 때문에 발생

### 어떤 코드/구조에서 문제가 있었는가?

- 이미지 처리 과정에서 저장 위치와 이미지 경로 관리 기준이 명확하게 정해져 있지 않아서 문제가 있었음.

- 게시글 작성 과정에서 업로드한 이미지를 처리하는 Controller와 조회 화면에서 사용하는 Thymeleaf 코드 간 이미지 경로 기준이 달랐고, 이미지 경로를 여러 위치에 조합하면서 중복 경로가 생성되거나 잘못된 URL로 요청되는 문제가 있었음.

## 🛠 해결 방법

### 어떻게 해결했는가?

- `/src/main/resources/static/uploads/images`에서 프로젝트 루트의 `uploads` 폴더로 변경

- `startWith()`를 사용하여 이미지 경로에 `/uploads/restaurant`가 이미 포함되어있는지 확인한 후, 없는 경우에만 경로를 추가할 수 있도록 수정.

> `startWith()` : 대상 문자열이 특정 문자나 문자열로 시작하는지 체크하는 함수

## 🧠 배운점

### 트러블 슈팅을 통해 깨달은 부분

- 이미지 업로드 기능을 구현하면서 파일 저장 위치와 DB에 저장되는 경로, 화면에서 불러오는 경로가 일치해야 정상 동작하는 것을 배움.

- 또한 문제 발생 시 코드를 수정하는 것보다 데이터가 저장되고 화면에 출력되는 전체 흐름을 확인하는 것이 중요하다는 것을 알게 됨.
