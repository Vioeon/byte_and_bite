## 📌 문제 발생

### 1. 문제 유형 (핵심 태그) 정의

- html 관련
- 데이터 처리

### 2. 어떤 기능에서 문제가 발생했는가?

- 마이페이지에서 일반사용자와 맛집운영자 화면에 각각 표시되는 항목이 달라서 회원 유형에 맞게 화면이 나타나도록 구현해야 했다. 유형별로 분류는 했으나 화면상 구현할 때 회원별 표시되는 항목이 잘못 노출되거나 디자인 부분이 조금씩 뒤틀리게 나오는 상황이었다.

- DB에서 로그인한 회원이 작성한 게시글에 대한 정보를 파악하여 마이페이지 화면에 표시되도록 해야 했는데 0건이라고 나왔다.

---

## 🔍 원인 분석

### 1. 왜 발생했는가? 어떤 코드/구조에서 문제가 있었는가?

- 일반사용자인 경우 표시되는 항목과 맛집운영자인 경우 표시되는 항목이 달랐는데 처음에는 일반사용자인 경우에 해당하는 코드를 누락했고, 표시되는 항목이 제대로 나오게 한 후에는 디자인 부분에서 불필요한 부분이 잘못 들어가서 이에 해당하는 코드를 수정하였다.

- DB에 데이터 자체가 없는 상황, DB에서 데이터를 못 가져오는 상황, DB에서 데이터는 가져오더라도 표시를 못하는 상황, 이렇게 세 가지 중 하나가 원인이라고 생각했다.

---

## 🛠 해결 방법

### 1. 어떻게 해결했는가?

- 직접 화면을 보면서 작성한 코드와 비교 및 분석하면서 회원별 표시되어야 하는 항목, 디자인 세부 사항까지 적절하게 나오도록 해결하였다.

- 팀장님의 도움을 받아서 로그를 통해 확인 후, 문제가 되는 쿼리문을 수정하여 DB에서 데이터를 가져와서 표시가 되도록 해결하였다.

---

## 🧠 배운점

- 유형별로 케이스 분류하여 그에 해당하는 화면이 표시되도록 코딩하는 방법을 알게 되었다.

- html 파일 내에서는 코드상으로 오류가 없더라도 코드 위치, 공백 등에 따라 세부적인 디자인에 영향을 준다는 걸 깨달았다.

- 화면에 데이터가 표시되지 않는 이유가 여러 가지 존재한다는 걸 배웠다.
